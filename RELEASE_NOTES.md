# v0.1.0 — first public release

The rc2 product solver/API is unchanged. This release adds public documentation,
MIT licensing and attribution, curated scientific evidence, reproducibility guidance,
package metadata, a release wheel and CPU CI. Private candidate tags remain historical.
The public verifier uses RELEASE_MANIFEST.json; it does not validate an old candidate.

Known limits: independent human custom-model integration is untested; references
are caller-supplied; the frozen study is narrow; GPU evidence predates this public
packaging release. No general speedup, energy or convergence guarantee is claimed.
